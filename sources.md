# Источники фактов и изображений

1. Официальный каталог Symbolics (1983) — описание Lisp-машин и позиционирование для лабораторий и университетов. Подтверждает характеристики Symbolics 3600 и стиль рекламы.
2. Журнал Byte (конец 1970‑х — начало 1980‑х) — примеры рекламы, типографика, плотность текста, обещания «интерактивности».
3. Документация Genera (ОС для Lisp-машин) — подтверждает, что ОС и инструменты написаны на Lisp.
4. Wikipedia (статьи про Lisp, Symbolics, Flavors) — для общей хронологии и ключевых вех. Использовал только для дат и названий проектов, важные факты перепроверял по первичным источникам.
