# Lisp и эпоха Lisp-машин: рекламная страница курсов

**Вариант:** 3 (Lisp)  
**Выбранная эпоха:** 1979–1985 (коммерциализация Lisp, Symbolics, Lisp Machines)  
**Автор:** Мусаев Артём 
**Группа:** ПИ - 261

**Смысл работы:** показать, как Lisp выглядел в эпоху Lisp-машин — не как «язык из учебника», а как полноценная платформа для ИИ. Рекламная страница имитирует стиль компьютерных журналов и каталогов конца 70-х — начала 80-х.

**Что сделано лично мной:**
- Выбрал эпоху 1979–1985, потому что именно тогда Lisp стал «платформой» (а не просто языком) — это видно по Lisp-машинам.
- Подобрал 4 источника и выписал из них только то, что напрямую связано с рекламой и визуалом.
- Придумал шутку про «Fortran-инженера» — она опирается на реальный контраст между пакетной обработкой и интерактивным Lisp.
- В `iterations.md` записал реальные проблемы, которые заметил при сборке.
